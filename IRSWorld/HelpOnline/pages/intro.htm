The IRSWorld Screen
    

    (1) URL Address Bar

    (2) User Name

    (3) Branch Name
            - Displays the branch name where the current user belongs

            - Displays the available menu for each user
            
    (6) Sub-Menu
            - Displays the available sub-menu
            
    (7) Version
            - Displays the version of IRSWorld
